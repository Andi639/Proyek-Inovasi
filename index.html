Cara Kerja Integrasi Nyata

Token Bot Telegram tidak boleh disimpan di kode front-end karena bisa dibaca siapa saja yang membuka halaman. Pada implementasi sebenarnya, alur pesan berjalan melalui backend:

→
Firebase Realtime DB
→
Cloud Function
→
Telegram Bot API
→
Grup Telegram RT

Cloud Function menyimpan token bot dengan aman dan memanggil sendMessage ke Telegram setiap ada data baru masuk ke Firebase.

1. Software (tahap ini)

Prototipe yang sedang kamu lihat: login/register, tombol panik simulasi, riwayat laporan, peta, dan simulasi notifikasi Telegram. Backend nyata menggunakan Firebase Authentication, Realtime Database/Firestore, dan Cloud Functions untuk menjembatani ke Telegram Bot API.

2. Hardware (tahap lanjutan)

ESP32 / NodeMCU
Mikrokontroler dengan WiFi bawaan, mengirim data ke Firebase saat tombol ditekan.
Push Button Darurat
Tombol fisik tahan tekan, dipasang di titik strategis rumah warga.
Modul GSM (SIM800L)
Cadangan komunikasi untuk area dengan sinyal WiFi lemah.
Buzzer / Relay Sirine
Mengaktifkan sirene terpusat pos ronda saat sinyal darurat diterima.
Modul GPS (opsional)
Jika titik pasang tombol berpindah; jika tetap, koordinat cukup didaftarkan sekali per rumah.
Baterai Cadangan
Menjaga perangkat tetap aktif saat listrik padam.

Catatan Pengembangan Lanjutan

Dua ide yang dapat dijadikan bab "saran pengembangan" di laporan: (1) tombol panik tetangga terdekat bisa ikut diaktifkan untuk rumah di sekitarnya saat pemilik rumah tidak sempat, dan (2) integrasi kamera CCTV yang otomatis mengirim cuplikan ke grup Telegram begitu sinyal darurat aktif.

Kirim Sinyal Darurat?

Tindakan ini akan tercatat sebagai laporan resmi dan langsung diteruskan ke grup Telegram RT. Gunakan hanya untuk keadaan darurat yang sungguhan.
